# 酒店订单列表按钮逻辑

> 记录 legacy 与当前重构版的酒店订单列表状态、按钮来源。本文仅覆盖国内酒店订单列表；短信验证码入口暂不纳入本次对齐范围。

## 概念边界

| 概念 | 含义 |
| --- | --- |
| 因公 / 因私 | 业务性质，表示订单属于企业差旅还是个人出行。 |
| `channel=tmc` | 企业差旅接口通道，对应 legacy `projects/ryx/src/app/tmc/...`。 |
| `channel=tourist` | 因私 / public 接口通道，对应 legacy `projects/ryx/src/app/public/...`。 |

## legacy 规则

### TMC RYX

来源：

- `projects/ryx/src/app/tmc/tmc-order/components/order-item_ryx/order-item_ryx.component.html`
- `projects/ryx/src/app/tmc/tmc-order/components/order-item_ryx/order-item_ryx.base.component.ts`

按钮：

| 按钮 | 展示条件 |
| --- | --- |
| 去支付 | `order.VariablesObj?.isPay`，并经 `checkIsPay()` 排除 `OrderStatusType.WaitHandle`。 |
| 取消订单 | `order.VariablesObj?.isShowCancelButton`。 |

### public / tourist

来源：

- `projects/ryx/src/app/public/public-order/components/order-item/order-item.component.html`
- `projects/ryx/src/app/public/public-order/components/order-item/order-item.component.ts`

按钮：

| 按钮 | 展示条件 |
| --- | --- |
| 去支付 | `order["checkPay"] && order.OrderHotels[0].StatusName != "取消中" && order.VariablesObj?.isPay`。 |
| 取消订单 | `order.OrderHotels[0].VariablesObj.isBtn == 1 && order.OrderHotels[0].VariablesObj.btnValue == "取消订单"`。 |

public 版本还会在旅客信息处展示房间级 `orderHotel.StatusName`；当前重构版列表暂只展示订单级 `StatusName`。

## 当前重构版落地

当前 H5 / Web 订单列表共用 API 归一化：

- `packages/api/src/apis/order.ts`：订单列表请求保留 `params.channel`，归一化时传入 channel。
- `packages/api/src/apis/order-list-map.ts`：酒店订单专用 `buildHotelActions(order, hotel, channel)` 生成列表按钮。
- `packages/shared-types/src/order.ts`：酒店列表项保留 `PaymentType` 与 `HotelStatusName`。
- `apps/h5/src/components/order/OrderListCard.tsx` / `apps/web/src/components/order/OrderListCard.tsx`：金额处展示支付方式，旅客处展示房间状态，订单级状态继续展示在卡片头部。

对齐策略：

| channel | 支付按钮 | 取消按钮 |
| --- | --- | --- |
| `tmc` | 非等待处理状态，且订单级 `VariablesObj.isPay` 为真。 | 订单级 `VariablesObj.isShowCancelButton` 为真。 |
| `tourist` | 非等待处理状态，房间级 `StatusName` 不是“取消中”，且订单级 `VariablesObj.isPay` 为真。 | 房间级 `VariablesObj.isBtn` 为真且 `btnValue == "取消订单"`。 |

短信验证码相关按钮不映射到当前 `OrderAction`，本次不展示。

## 三类信息的展示位置

| 展示位置 | 字段 | 示例 |
| --- | --- | --- |
| 金额旁 | `OrderHotels[0].PaymentType` | `预付` / `到店付` |
| 卡片头部 | `order.StatusName` | `交易完成` / `交易取消` |
| 旅客姓名后 | `OrderHotels[0].StatusName` | `预订成功` / `退单` / `废除` |

订单级状态与房间级状态可以同时出现且不冲突。例如订单显示“交易完成”，旅客后显示“退单”，分别代表订单生命周期和酒店房间处理结果。
