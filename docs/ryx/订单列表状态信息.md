# 订单列表状态信息

> 记录国内机票、火车票、酒店订单列表中订单级、票据级、房间级及金额附加信息的展示来源。

## 共同规则

| 展示位置 | 字段 | 含义 |
| --- | --- | --- |
| 卡片头部 | `order.StatusName` | 订单级生命周期状态，例如 `交易完成` / `交易取消` / `待支付`。 |
| 金额旁 | `OrderInsurances` 或 `VariablesObj.insuranceAmount` | 机票、火车票显示 `含保险`。 |

## 机票

| 展示位置 | 字段 |
| --- | --- |
| 旅客姓名后 | `OrderFlightTickets[].AppStatusName ?? StatusName ?? Status` |

legacy public 将机票状态展示为 `旅客姓名（票状态）`；当前 H5/Web 与此对齐。

## 火车票

| 展示位置 | 字段 |
| --- | --- |
| 旅客姓名后 | `OrderTrainTickets[].AppStatusName ?? StatusName ?? Status` |
| 异常通知 | `OrderTrainTickets[].VariablesObj.CommandPrompt` |

legacy TMC RYX 会展示 `CommandPrompt` 作为红色异常通知；当前 H5/Web 与此对齐。

## 酒店

酒店的金额支付方式、订单状态和房间状态见 [酒店订单列表按钮.md](./酒店订单列表按钮.md)。
